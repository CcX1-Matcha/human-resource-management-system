# 人力资源管理系统 Implementation Plan

> **For agentic workers:** Use the executing-plans workflow and independent frontend/backend agent tasks. Follow the fixed API contract and verify integrated behavior.

**Goal:** 交付可本地启动、覆盖文档六大模块的中文人力资源管理程序。

**Architecture:** SQLite 持久化后台与元数据驱动的中文管理界面。HTTP 层负责会话、CSRF、静态资源和接口路由，业务层负责验证、权限、工资与统计。

**Tech Stack:** Python 3.10+ 标准库，SQLite，原生 HTML/CSS/JavaScript。

**Spec:** docs/superpowers/specs/2026-10-12-hrm-design.md

## Global Constraints

- Windows 10 与现代浏览器可运行，无第三方运行依赖。
- 所有业务数据持久化；服务端校验权限、输入、关联和工资状态。
- 中文界面；提供明确错误与空状态；CSV 兼容 Excel。
- 使用上述设计内完整 API 与 HRMService 契约。
