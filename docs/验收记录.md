## 浏览器覆盖

实际验收了登录与注销、首页、全部24类记录页面与新增表单、员工新增/编辑/搜索/查看、关联下拉、生日日期、统计图与明细、社保小数比例、工资生成与发放、通知新增/删除/打印准备、关联删除保护、CSV下载、导航与字典配置、390像素窄屏布局，以及查询用户的导航和禁止写入界面。

通知打印验证调用了浏览器打印入口并准备正确的独立打印内容；不涉及实体打印机出纸。工资发放验证的是数据库发放状态，不涉及银行转账。

## 复核方式

```text
python -m unittest discover -s tests -v
node tests/test_frontend.cjs
```

浏览器测试为可选开发验收脚本，需要Node、Playwright与Edge。先启动专用演示数据库和独立端口，再设置环境变量PLAYWRIGHT_PATH及HRM_TEST_URL，运行 `node tests/test_frontend_browser.cjs`。该脚本会创建演示记录并确认工资发放，务必使用专用测试库。
