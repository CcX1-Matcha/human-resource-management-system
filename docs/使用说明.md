# 人力资源管理系统使用说明

## 第一次运行

1. 双击项目目录的 `start.bat`，等待浏览器打开。
2. 如果浏览器没有打开，手动访问 `http://127.0.0.1:8000`。
3. 使用 `admin` 和 `Admin123!` 登录。
4. 首页展示人员数量、待处理请假、月度工资、部门人员和生日提醒。初始业务记录都是演示数据。
5. 先在系统设置检查部门、角色和社保比例，再维护真实员工。需要全新业务库可按 README 的 `--no-seed` 方式启动独立文件。

## 员工档案与人事业务

1. 进入人事管理下的职工管理，点击新增。
2. 输入工号、姓名、部门、入职日期，补充性别、生日、学历、岗位、联系方式和基本工资。
3. 保存后用姓名或工号搜索。点击编辑可修改档案；离职员工应维护离职状态和离职日期。
4. 在职工社保中选择员工，填写参保基数和参保状态。
5. 在奖罚登记中选择员工、奖罚类型、金额和日期。
6. 在职工调动中选择员工、目标部门和岗位。保存成功后员工当前部门和岗位同步更新。
7. 在证书管理中登记证书和有效期；在实习生管理中登记学校、实习部门与期限。
8. 在请假管理中登记请假类型、起止日期、天数、是否带薪和原因。审批状态用于后续工资核算，待审批和拒绝的记录不作为已批准无薪假扣款。
9. 职工生日页面显示未来生日及距离天数，可按提醒范围查询。

所有删除操作均需确认。有下游业务记录的员工或组织可能无法删除，应先处理关联记录，或保留员工并更新离职状态。

## 培训

1. 在课程管理登记课程名称、分类及相关资料。
2. 在内部培训或一线工培训中选择课程和员工，填写日期、结果和备注。
3. 利用搜索查看员工培训记录，可导出用于实践演示。

## 月度工资

1. 在薪酬级别和加班标准中维护基础配置。
2. 员工基本工资在职工档案中维护；社保基数在人事社保记录中维护，比例由管理员配置。
3. 在水电费、加班登记、计件工资和计时工资中录入该月数据。
4. 检查人事奖罚和已批准的无薪假记录。
5. 打开“工资档案与发放”，选择月份，点击生成月度工资。
6. 检查工资明细中的基本工资、各项收入、社保及扣款、应发与实发。
7. 若未发放且原始登记有变化，可再次生成当月工资。
8. 在同一页面逐条、勾选或整月确认发放。已发放记录不能被重复发放或重新生成覆盖。
9. 导出工资数据为 CSV，用 Excel 打开查看。

发放为程序内的确认记录，不涉及银行账户或实际转账。计算口径与范围见 README。

## 查询、通知与统计

1. 公共查询支持员工姓名、工号搜索及部门、状态筛选。
2. 通知页可新增或编辑标题、内容和发布日期。
3. 点击通知打印，在浏览器打印窗口选择打印机或另存为 PDF。
4. 报表页面选择年度，查看性别、学历、年龄、工龄、部门和各月入离职统计；查看离职率时请同时关注界面或设计文档所列统计口径。
5. 记录列表的导出按钮导出当前查询结果。

## 用户与权限

1. 管理员在组织结构维护部门。
2. 在“角色与权限”中选择该角色允许使用的模块。
3. 在用户管理中创建账号，关联角色，设置密码和启用状态。
4. 编辑用户时，密码留空表示保留原密码；填写新密码后保存表示修改密码。
5. 角色管理与系统权限合并在“角色与权限”页面。后台会校验权限，直接调用接口也无法绕过。
6. 导航菜单可以配置菜单名称、排序和可见状态，保存后立即生效。系统设置菜单保留显示，以便恢复其他菜单。
7. 数据字典维护分类选项记录；类别填写“学历”或“假别”时，启用的新选项会分别用于员工档案和请假表单，默认选项保留。

## 数据保存与排错

- 页面刷新或程序重启不会清除保存的数据。
- 修改失败时按页面的具体错误检查必填项、日期、关联人员和权限。
- 登录失效时重新登录；会话在服务重启后也需要重新登录。
- 服务窗口出现端口占用时使用 `python app.py --port 8001 --open`。
- 备份前停止服务，复制实际使用的数据库文件；恢复前也应停止服务。
- 关闭运行窗口或按 Ctrl+C 后网页不能继续保存，需要再次启动。
