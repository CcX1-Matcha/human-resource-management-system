# 人力资源管理系统

根据《软件综合实践》文档实现的中文人力资源管理程序，包含人事、培训、薪酬、公共查询、报表统计和系统设置。所有记录保存在本地 SQLite 数据库，关闭后重新启动仍可使用。

## 启动

Windows 双击 `start.bat`，程序会启动服务并打开浏览器。也可在项目目录使用 Python 3.10 或以上版本运行：

```text
python app.py --open
```

浏览器地址：<http://127.0.0.1:8000>。运行窗口需要保持打开，按 Ctrl+C 停止。

本程序无第三方运行依赖，不需要 npm、数据库服务器或额外 Python 包。启动脚本优先使用 Python 启动器，也支持当前 Codex 环境的 Python。

首次启动自动创建 `data/hrm.db` 和演示数据。需要空业务数据库时使用 `python app.py --db data/clean.db --no-seed`，仍保留登录账号和基础系统配置。端口占用时使用 `python app.py --port 8001 --open`。

## 文档功能对应

| 文档模块 | 已实现功能 |

| 人事管理 | 职工档案、社保、奖罚、调动、证书、实习生、请假、生日 |

文档重复列出的“社保比例”合并为一个配置功能。教学考勤、评分、向校友邦提交材料等要求不属于程序功能，程序不会代替学生填写或上传这些材料。

## 工资计算口径

工资按月份归集：

```text
应发 = 基本工资 + 加班工资 + 计件工资 + 计时工资 + 奖励
实发 = 应发 - 处罚 - 水电费 - 个人社保 - 已审批无薪假扣款
```

个人社保按员工参保基数和社保比例计算，企业社保单独显示；无薪假按基本工资 / 21.75 折算。发放前可以重新生成当月工资；已发放的工资保留原明细，不重复发放、不被重算覆盖。金额保留两位小数。

这是文档未指定税费规则情况下的课程核算口径。个税、法定月中入离职折算、实际银行转账、地区社保上下限未纳入本程序；“发放”记录的是系统内确认，不会向银行发送付款。

## 测试和备份

```text
python -m unittest discover -s tests -v
```

测试使用临时数据库，不更改实际业务库。备份前停止程序，复制 `data/hrm.db`；恢复时停止程序，再用备份替换该文件。整个工程文件可直接复制到另一台安装 Python 3.10+ 的 Windows 电脑运行。

默认监听本机地址，面向本地课程实践。若部署为多人或公网系统，需要补充 HTTPS、部署服务、备份策略、并发审批和业务政策配置。
